# CLAUDE.md — SpAM_Task

Online Spatial Arrangement Method (SpAM) task for collecting human perceptual similarity judgements
over 754 object images. Built with jsPsych, hosted on Pavlovia, recruiting via Prolific.

> **Full research & implementation plan**: `PLAN.md` at the repo root (gitignored — not yet published).
> Read it before making significant changes to parameters, QC logic, or trial design.

    utils.js                ← hashString, seededShuffle, computePairwiseDistances, computeSD

Stimuli live **outside this directory** at paths specified in `config.json`.

## generate_manifest.py

Browsers cannot list the contents of a server directory, so `task.js` cannot discover which
image files exist at runtime. `generate_manifest.py` solves this: it reads the stimuli paths
from `config.json`, scans those directories, and writes `stimuli_manifest.json` — a flat list
of all available image filenames for each stimulus set (main, practice, catch). Run it once
after any change to the stimulus directories, before testing or deploying.

```bash
# from SpAM_Task/
python generate_manifest.py
```

## Key Design Decisions

**Stimulus assignment**: Client-side seeded RNG. Seed = `hashString(PROLIFIC_PID)` (djb2).
Each subject gets `N_unique=150` images across `t=10` trials of `k=20` images. 50 images
appear in exactly 2 trials (within-subject reliability); 100 appear once. No image repeats
within a single trial.

**Pre-loading**: `jsPsychPreload` inserted immediately before each free-sort trial — loads only
that trial's `k` images on demand, not all 150 at the start.

**jsPsych plugin**: `jsPsychFreeSort`. Images passed as plain URL strings; the plugin wraps
them in `<img>` elements automatically. Output per trial: `final_locations: [{src, x, y}, ...]`.

**Distance normalisation**: All pairwise Euclidean distances from `final_locations` are divided
by the sort-area diagonal `√(width²+height²)` → [0, 1]. Removes dependence on screen resolution
and sort-area size, making measurements comparable across participants.

**Catch trials**: 2 catch trials interleaved at positions ~trial 3 and ~trial 7. Each uses a
fixed 20-image set (same across all subjects) from the catch stimulus directory. Failure = SD
of normalised pairwise distances below the same threshold as main trials.

**Quality control**: Flag a trial if SD of normalised pairwise distances < `min_pairwise_distance_sd`
(default 0.04) OR `rt` < `min_trial_rt_ms` (default 5000 ms). Exclude a participant if > 30%
of their trials are flagged.

**Pavlovia saving**: At end of experiment, POST jsPsych CSV to Pavlovia's session results API.
Detect Pavlovia by checking `window.location.hostname`. Fall back to local CSV download for
testing.

## Running Locally (testing)

1. Set stimulus paths in `config.json` and populate those directories
2. Run `python generate_manifest.py` from `SpAM_Task/`
3. Serve with a local HTTP server (e.g. `python -m http.server`) — required because
   `task.js` fetches `config.json` and `stimuli_manifest.json` via `fetch()`
4. Open `http://localhost:8000` and append `?PROLIFIC_PID=test123` to use a fixed seed;
   set `"debug": true` in `config.json` for extra console logging

## config.json Parameters

| Key | Default | Description |
|---|---|---|
| `stimuli_path` | `""` | Path to the 754 dataset images (relative to `index.html`) |
| `stimuli_practice_path` | `""` | Path to practice trial images |
| `stimuli_catch_path` | `""` | Path to catch trial images |
| `trials_per_subject` | 10 | Number of main free-sort trials |
| `images_per_trial` | 20 | Images shown per trial |
| `unique_images_per_subject` | 150 | Unique images assigned per subject |
| `num_catch_trials` | 2 | Catch trials interleaved among main trials |
| `practice_images_per_trial` | 8 | Images in the (discarded) practice trial |
| `sort_area_width/height` | 900 / 700 | Sort canvas size in px |
| `sort_area_shape` | `"square"` | `"square"` or `"ellipse"` |
| `image_width/height` | 100 / 100 | Stimulus display size in px |
| `min_trial_rt_ms` | 5000 | Minimum acceptable trial duration |
| `min_pairwise_distance_sd` | 0.04 | Minimum SD of normalised distances (QC) |
| `prolific_completion_url` | `""` | Set before deploying to Prolific |
| `debug` | `false` | Use fixed seed and log extra info to console |
